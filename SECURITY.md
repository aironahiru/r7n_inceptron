# Security Policy

Inceptron is in early development and has no releases yet. Still, if you find a security problem, we want to hear about it.

## Reporting a vulnerability

Please **do not open a public issue** for security vulnerabilities. Instead, report them privately through GitHub:

1. Go to the [**Security** tab](https://github.com/aironahiru/r7n_inceptron/security) of this repository.
2. Click **Report a vulnerability**.
3. Describe the problem, how to reproduce it, and what impact you think it has.

We'll acknowledge your report as soon as we can and keep you updated as we work on a fix.

## Soundness bugs

For a theorem prover, the most serious kind of bug is one that lets a false statement be "proved". If you find one, please report it with the **Bug report** template and tick the *soundness* box, or report it privately as described above if you prefer.
